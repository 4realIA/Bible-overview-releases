# Bible Overview

The King James Bible with an overview of every book: who wrote it and when,
the major events, the people involved, and the key verses. Bookmarks and
notes, reading aloud, and the meanings of old words. Works offline; nothing
you write leaves your computer.

**[Download the latest version](https://github.com/4realIA/Bible-overview-releases/releases/latest)**

## Windows

1. Under *Assets*, download the file ending in **`windows_x64-setup.exe`** and open it.
2. If Windows says **"Windows protected your PC"**, click **More info**, then
   **Run anyway**. This shows only the first time, because the app is new.
3. Click through the installer. No administrator password is needed.

## Mac (Apple silicon)

1. Under *Assets*, download the file ending in **`macos_arm64.dmg`** and open it.
2. Drag **Bible Overview** into **Applications**, then open it from there.

The Mac app is signed and notarized by Apple, so it opens with a double-click.

## Updates

Bible Overview keeps itself up to date. On a Mac the new version is used the
next time you open the app; on Windows it installs when you close the app.

## The Bible text

King James Version (1769 standard text), public domain.
